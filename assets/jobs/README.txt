Photo Asset Drop Folder for Lungrin's Lawncare
=================================================

To use Luke's original Facebook or phone camera photos on the website:
1. Save the image files from Facebook / phone into this folder (`assets/jobs/`).
2. Recommended filenames:
   - `mowing-flora.jpg`
   - `pine-straw-pocahontas.jpg`
   - `pond-bank-clearing.jpg`
   - `hedge-trimming.jpg`
   - `gutter-cleaning.jpg`
   - `yard-cleanup.jpg`

The website is pre-configured with high-resolution responsive cards that can seamlessly link to these local image files whenever you add them!
